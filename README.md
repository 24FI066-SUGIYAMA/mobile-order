# GOOD EATS | モバイルオーダー

[インタラクティブメディアとデザイン](https://els.sa.dendai.ac.jp/webclass/course.php/202611080414010101/)の最終課題として制作した、モバイルオーダーシステムです。

飲食店のテーブル注文を想定した、タブレット向けの注文画面デモです。来店人数の選択から、メニューの閲覧、商品オプションの選択、注文確定、注文履歴の確認までをブラウザ上で体験できます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 来店受付 | スタート画面から来店人数を選択。1〜12名に対応 |
| メニュー表示 | 全18商品を写真・説明・価格付きで表示 |
| カテゴリ切り替え | おすすめ、グランドメニュー、季節限定、サイドメニュー、ドリンク、デザート |
| オプション選択 | 対象商品でご飯の量、サイズ、セットを選択し、価格へ反映 |
| 注文リスト | 商品の追加、数量変更、数量を0にして削除 |
| 金額計算 | 商品とオプションの小計、サービス料10%、合計を自動計算 |
| 注文確定 | 注文内容・点数・合計を表示し、注文リストをリセット |
| 注文履歴 | 確定済みの商品、累計点数、累計金額を確認 |

## 操作方法

1. 「はじめる」を押します。
2. 来店人数を選び、「メニューを選ぶ」を押します。
3. 左側のカテゴリから商品を探し、「＋」を押します。
4. オプションがある商品は内容を選び、「注文リストに追加」を押します。
5. 右側の注文リストで数量と合計を確認します。
6. 「注文へ進む」を押すと注文が確定し、完了画面が表示されます。
7. 「注文履歴」から確定済みの注文を確認できます。追加注文も可能です。

## ローカルでの起動方法

Node.jsとnpmが必要です。外部パッケージを使っていないため、`npm install`は不要です。

```bash
git clone https://github.com/24FI066-SUGIYAMA/mobile-order.git
cd mobile-order
npm run dev
```

ブラウザで <http://localhost:5175> を開いてください。終了するときはターミナルで `Ctrl + C` を押します。

通常起動は次のコマンドでも可能です。この場合は <http://localhost:3000> で表示されます。

```bash
npm start
```

ポートを変更する場合は、macOSなどの環境で次のように指定できます。

```bash
PORT=8080 npm start
```

ローカルサーバーは `127.0.0.1` で待ち受けるため、同じパソコンからアクセスします。

## メニュー・料金の変更

- 商品名・説明・価格・画像・所属カテゴリ：`public/app.js` の `menuItems`
- カテゴリ名：同ファイルの `categories`
- オプションの内容・追加料金・対象商品：同ファイルの `optionGroups`
- サービス料の計算：同ファイルの `getServiceFee()`
- 画面の見た目：`public/styles.css`

現在の金額計算は次のとおりです。商品価格は画面上で税込として扱い、消費税の別途加算は行いません。

```text
商品単価 = 商品の基本価格 + 選択したオプションの増減額
小計 = 各商品の「商品単価 × 数量」の合計
サービス料 = 小計 × 10%（円単位で四捨五入）
合計 = 小計 + サービス料
```

サービス料率を変更するときは、画面の「サービス料（10%）」という表記も合わせて変更してください。

## 現在の仕様・制限

- 注文処理はブラウザ内で完結するデモです。実店舗や厨房への注文送信は行いません。
- 注文リスト・注文履歴・来店人数はページを開いている間だけ保持され、再読み込みするとリセットされます。
- データベース、CSV保存、ログイン、店員向け管理画面、決済機能は実装していません。
- 「注文を受け付けました」という表示はデモ上の完了表示です。
- 画面はタブレット向けの構成を基準に、ウィンドウ幅に合わせて拡大・縮小します。スマートフォン専用の画面構成はありません。
- Google Fontsの読み込みにはインターネット接続が必要です。
